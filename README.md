# Skills

A collection of skills for [Claude Code](https://claude.ai/code) — some adapted from existing sources, some created from scratch.

Skills are slash commands you can invoke in Claude Code (e.g. `/checkpoint`). Drop a skill file into your project's `.claude/` folder or your global `~/.claude/` folder to make it available.

---

## Skills

### [Checkpoint](checkpoint.md)

Quiz yourself on code you just wrote or changed. Claude reads the diff, generates targeted multiple choice, true/false, and open-ended questions, and scores your understanding. Good for cementing knowledge after a focused session.
